# Xiji Hang — Data Science Portfolio

Live website: https://xijihang.github.io/data-science-portfolio/

Project repository: https://github.com/XijiHang/data-science-project

This portfolio presents my completed PM2.5 forecast evaluation from CISC7204 Practice 07. It introduces the research question, compares forecast error with high-concentration detection, explains the validation method and states the limits of the historical benchmark.

## Publish

In **Settings → Pages**, choose **Deploy from a branch**, **main**, **/ (root)**, and save. `index.md` is the website entry file. GitHub Pages uses Jekyll to render the root `index.md` with its embedded HTML shell and `_config.yml`. The page uses local CSS, JavaScript and SVG files; no third-party tracking, web fonts or API keys are needed.

## Files

- `index.md`: name, introduction, skills, completed project and findings.
- `style.css`: responsive layout and visual styling.
- `script.js`: buttons to switch between the two chart views; without JavaScript both figures remain visible.
- `error-comparison.svg` and `alert-tradeoff.svg`: SVG figures generated by `plot_results.py` in the project repository.
